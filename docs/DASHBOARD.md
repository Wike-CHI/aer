# AER 只读经验看板

安装 `pip install '.[web]'`，配置 `AER_DATA_DIR`、`AER_DB_PATH`（如有覆盖）与
`AER_KNOWLEDGE_DIR` 为该实例的绝对路径。启动时沿用 AER 的迁移机制；升级前必须备份。
HTTP 数据请求只读取既有 Runtime/Repository，不提炼、不检索、不记录使用、不修改状态。

后端环境文件（权限 0600，禁止提交）：

```dotenv
AER_DASHBOARD_PASSWORD=<至少16字符的随机口令>
AER_DASHBOARD_SESSION_SECRET=<至少32字符的独立随机密钥>
```

运行 `python -m aer.dashboard --host 127.0.0.1 --port 8788`。
通过 `ssh -L 8788:127.0.0.1:8788 bwg-06` 建立隧道，然后打开
`http://127.0.0.1:8788`。Docker 中监听 `0.0.0.0`，宿主端口必须只绑定回环。
不要将 HTTP 服务直接暴露公网。使用 HTTPS 反代时需另行配置和验收。

浏览器不保存口令或 API token。登录后使用一小时 HMAC 签名 HttpOnly/SameSite cookie，
登录每分钟最多十次尝试（实例级），响应禁止缓存，页面只用 textContent 展示数据。
退出清除当前浏览器 cookie；轮换 session secret 可使所有会话失效。当前为单一操作者
口令，不提供用户管理或多租户隔离。持有看板口令的人可以读取该实例技术轨迹。

总览展示库内任务/经验/检索会话/注入条目计数和状态分布。趋势与验证指标只取最近
100 个 Run，明确显示样本量；不能据此声称全库成功率。
采用信号分布仅取最近 100 个检索会话，UNKNOWN 单独保留，不当作未采用。
任务列表每页 25 条，接口上限 100 条，支持状态筛选。
任务详情展示声明、独立验证、事件、错误和恢复，附事件总数；
事件按 offset/limit 分页，其他明细每类最多 100 条。经验详情包含来源任务及最近
100 条使用记录。UNKNOWN 保持未知，检索、注入、采用和任务结果彼此独立。

没有任务时显示空状态，不向生产库插入演示记录。`/healthz` 仅返回进程健康，不读取库。
部署健康还应登录后访问 `/api/overview` 验证真实数据库可读。

验证：`pytest tests/dashboard`，覆盖认证、过期/伪造会话、登录限速、分页边界、未知结果
不误判成功，以及读取前后 Run/Event/Usage/检索会话计数不变。
